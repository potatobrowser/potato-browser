What gets peeled

The AI Shield knows the AI features of the sites people use most and peels them off before the page finishes loading. The articles, results and messages stay put, like a potato on a couch. Want the AI back on one site? The shield button in the toolbar brings it back there and nowhere else.

Ads and trackers, mashed

Potato Browser comes with an ad blocker, switched on from the first page. Banners, pop-ups, video ads and the tracking scripts that follow you from site to site never load, so pages come up lighter and faster and nobody keeps notes on what you read.

It runs on the same open filter lists as uBlock Origin: EasyList, EasyPrivacy and uBlock's own, including the fixes that keep video ads off YouTube. Nothing to install, nothing to set up.

Want to support a site? The ad blocker button in the toolbar lets its ads through, there and nowhere else. Cookie banners and newsletter pop-ups can go too, one switch each in Settings. The lists freshen up daily through this site; the request names the lists, never you or the pages you visit.

Keep your eyes peeled. Flag the AI posts.

A potato has plenty of eyes, and so does this browser. Every post on Reddit, X, Instagram, Facebook, Threads, LinkedIn, YouTube, Bluesky and TikTok gets a small "AI?" button. When enough people flag a post, your browser does what you chose:

Flagged posts stay in your feed with an AI label, like a sticker on the sack.

Flags are anonymous. No account, no email. When your browser checks a page, it sends only the first five characters of a fingerprint of each post, which thousands of other posts share. Post ids, links and page contents never leave your Mac. Your own flag is stored under a scrambled id that cannot be traced back to you, and private windows flag under a new one each time. Open source, down to the roots

Every line of Potato Browser is on GitHub under the MIT license: the browser, the AI Shield rules and the flag service behind this site. Read it, fix it, or plant your own.

The downloads here are built in public. GitHub Actions grows each release from its tagged commit, keeps the build log, and signs an attestation that ties every DMG to the exact source it came from. Nothing gets added in a back room.

Grow your own

On a Mac with macOS 13 or later, Node.js 22 and pnpm 12:

git clone https://github.com/potatobrowser/potato-browser
cd potato-browser
pnpm install
pnpm --filter @potato/browser dist --arch host

The DMG for your Mac lands in apps/browser/release. A potato you grew yourself opens without a warning too.

Questions

Why a potato?

Potatoes are about as un-artificial as it gets. They grow in dirt, they don't write your emails, and nobody has ever asked one to summarize a meeting. That's the browser we wanted.

Is it free?

Yes, and open source under the MIT license. No account, no subscription, and no ads (we block those). Cheaper than a sack of spuds.

Can I see the AI on a site when I actually want it?

Yes, and we won't judge. Click the shield in the toolbar and switch it off for that site. Everything comes back right away, on that site only. Settings has the full list of covered sites and features if you'd like to keep a few of them.

Why block ads in a no-AI browser?

Because they grow in the same patch. A lot of the generated filler on the web exists only to show ads, and the ad networks are the trackers that follow you from site to site. Keeping the web human means keeping those off your plate too.

Will the ad blocker break sites?

Rarely. It uses uBlock Origin's lists, which carry fixes for sites that misbehave and update every day. If a site still acts up, press the ad blocker button in the toolbar and switch it off for that site. The page reloads with everything back, on that site only.

What does the ad blocker send?

Nothing about you. All matching happens on your Mac. Once a day the browser asks this site which version of each filter list is current and downloads the ones that changed. The request names the lists, never you or the pages you visit. You can turn updates off in Settings.

Can't people just flag everything?

Not easily. Each install counts once per post, and so does each network: flags coming from one home or office connection count once, however many installs they claim to be. There is also a daily limit per install. You choose how many flags it takes before a post counts as AI-generated, and a buried post is always one click away.

What exactly does the flag service store?

For each flagged post: a one-way fingerprint of the post's id, the platform name, and a count. For each flag: a scrambled version of your browser's random id, so you can undo it, the hour it was made, for the daily limit, and a network bucket, a number from 0 to 65,535 derived from the first part of your IP address. Hundreds of networks share every bucket, so it identifies no one; it only stops one connection from flagging a post twice. No IP addresses, no URLs, no accounts.

Why do downloads come from GitHub?

So you can check them. Each release is built by GitHub Actions from the public source, and GitHub keeps the build log and a signed record of the commit it came from. Run gh attestation verify on the file to confirm it. GitHub serves the file, so it sees the download like any website would. This site only counts downloads per day.

Is the app signed?

Yes. Every release is signed with an Apple Developer ID and notarized by Apple, so macOS opens it without a warning. Check it yourself with spctl --assess -vv "/Applications/Potato Browser.app": it should say Notarized Developer ID.

Does it support extensions and saved passwords?

Not yet, they're still sprouting. You won't miss an ad blocker extension, since one is built in. Your password manager's own app works alongside it in the meantime.

Windows or Linux?

Mac only for now. Other soils, maybe later.
